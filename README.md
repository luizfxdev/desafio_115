A Jornada do Código Épico: A Espada do Retorno de Strings


🧙‍♂️ Bem-vindo, bravo aventureiro! Você está prestes a embarcar em uma missão lendária no mundo mágico do JavaScript. Seu objetivo é recuperar a poderosa Espada do Retorno de Strings, um artefato que tem o poder de converter uma frase comum em uma frase encantada!

A missão é simples: você receberá uma string que contém várias palavras separadas por espaços. Sua tarefa é escrever uma função que retornará a string com as palavras em ordem reversa! Mas, cuidado! Você não deve reverter os próprios caracteres das palavras, apenas a ordem em que elas aparecem!

⚙️ Formato de Entrada:
Uma única string consistindo de palavras e espaços, sem pontuações.

🔮 Exemplo de Entrada:
const frase = "viva no mundo da codificação";

🏆 Saída Esperada:
"codificação da mundo no viva"
